项目流程

  • 清洗 TotalCharges 缺失值并统一字段类型。
  • 数值特征标准化，类别特征进行独热编码。
  • 五折分层交叉验证比较两种分类模型。
  • 保存完整 Pipeline，避免训练与预测预处理不一致。
  • 通过 FastAPI 提供健康检查、模型信息和预测接口。
  • 使用 Pydantic 校验输入范围与类别。

模型选择

  • 逻辑回归：交叉验证 AUC 84.60%
  • 随机森林：交叉验证 AUC 84.35%
  • 使用类别权重处理流失客户占比较低的问题
  • 最终模型 Recall 78.34%，优先识别潜在流失客户
